## Biografia

Simone Frigerio is a Cybersecurity Architect at Microsoft with a strong focus on Security Operations, cloud security, and modern security architecture.He specializes in Microsoft Sentinel, Defender XDR, Zero Trust, identity and cloud security, helping organizations design and evolve security architectures across complex cloud and hybrid environments.A key area of his work is the evolution of the Security Operations Center through AI, automation, Security Copilot, and AI agents, exploring how these technologies can improve investigation, detection, response, and security operations at scale.Simone joined Microsoft in 2019 and is an active technical speaker and community contributor, passionate about sharing practical lessons, architecture patterns, and real-world security experiences.
